# Specs

What the arcade does, one file per area. `TEMPLATE.md` is the starting point for
a new one, and `CLAUDE.md` in the repo root describes the flow.

Specs are numbered in the order they were written. The number is an identifier,
not a priority, and it never changes once a spec exists.
